# Visual asset provenance

## `sartrace-workflow.svg`

Animated SVG workflow illustration for the README. The diagrams show the stages of the SARtrace pipeline; the accompanying real-data section links directly to OMBRIA Sentinel-1 example chips. The workflow graphic is an explanatory illustration, not a recording of a satellite pass or a live application session.
